# BotFather — тексты для ДЗника

Вставь в [@BotFather](https://t.me/BotFather) по очереди.

## /setname

```
ДЗник · домашние задания
```

## /setabouttext

```
Школьный бот ДЗ: сегодня, завтра, неделя и расписание. Класс выбираешь один раз — дальше всё в два тапа.
```

## /setdescription

```
ДЗник показывает домашние задания твоего класса: сегодня, завтра, неделя и любой день.

Что умеет:
• ДЗ текстом и с фото
• расписание уроков
• напоминания вечером
• своя нижняя клавиатура

Ученик только смотрит. Админ класса добавляет ДЗ за минуту.

Жми Start, выбери класс — и всё.
```

## /setcommands

(Команды также выставляются ботом при запуске через API.)

```
start - Начать и открыть меню
menu - Главное меню
day - ДЗ на сегодня
next_day - ДЗ на завтра
week - ДЗ на неделю
schedule - Расписание
me - Профиль и уведомления
help - Как пользоваться
```

Админские `/reg`, `/edit`, `/stats` в меню Telegram не публикуем — они есть в кнопках бота.
