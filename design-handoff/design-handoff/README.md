# Пакет передачи дизайна HW-Helper

Этот пакет предназначен для агента, который будет переносить дизайн в исходный сайт.

## Содержимое

- `design/Homepage.tsx` — исходник очень тёмной главной страницы. Он сделан для React-превью и служит эталоном внешнего вида; не вставляйте его в сайт без адаптации.
- `design/themes/` — исходники восьми дополнительных цветовых вариантов: светлого, бежевого, синего, бело-синего, фиолетового, чёрно-синего, тёмно-серого и красного.
- `reference/desktop.jpg` и `reference/mobile.jpg` — снимки макета на компьютере и телефоне.
- `source-original/` — HTML-страницы и CSS, приложенные к проекту; сохраняют исходные шаблоны и структуру для переноса оформления.
- `APPLY_PROMPT_RU.md` — готовое задание, которое можно передать следующему агенту вместе с этой папкой.

## Направление дизайна

- Тёмная спокойная основа с мягким зелёно-мятным акцентом.
- Дополнительные темы сохраняют ту же структуру и меняют палитру для удобного сравнения.
- Основные цвета из макета: фон `#101917`, поверхности `#17221f` и `#1c2925`, основной текст `#eef5ec`, приглушённый текст `#a6b6ab`, акцент `#b7f08b`.
- Типографика: Manrope для основного текста и DM Mono для коротких служебных подписей.
- На широком экране первый экран разделён между сообщением о продукте и примером расписания; на узком блоки перестраиваются в одну колонку.
- Страница включает краткое объяснение сервиса, демонстрацию заданий и расписания, Telegram и будущую версию для Макс, регистрацию/вход, новости, помощь и ссылки в подвале.

## Важно при переносе

Макет — визуальный пример, а не готовая замена работающего сайта. Данные о заданиях и расписании демонстрационные; ссылки, регистрация, новости, поддержка и Telegram в макете не подключены. Сохраните действующие маршруты, отправку форм, проверку доступа, серверные подстановки, конфигурацию бота и источники новостей из настоящего приложения. Для содержимого используйте данные приложения, а не примеры из макета.
