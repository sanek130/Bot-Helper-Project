# Политика конфиденциальности HW-Helper

**Дата обновления:** 1 ноября 2026

## 1. Какие данные мы собираем

### Telegram-бот

- **Telegram ID (tgId)** — уникальный идентификатор вашего аккаунта в Telegram
- **Имя и username** — для отображения в интерфейсе
- **Город, школа, класс** — для привязки к домашним заданиям
- **Спец-ID (UUID)** — ключ для синхронизации аккаунта между ботом и сайтом
- **Домашние задания и расписание** — которые вы просматриваете или добавляете
- **Статистика** — количество просмотров ДЗ, дата последней активности

### Сайт

- **Спец-ID** — для входа в аккаунт
- **JWT-токен** — для авторизации (хранится в cookie, срок 30 дней)
- **IP-адрес** — для защиты от злоупотреблений (не хранится постоянно)

## 2. Зачем мы собираем эти данные

- **tgId** — чтобы бот мог отправлять вам сообщения и код для входа на сайт
- **Город/школа/класс** — чтобы показывать ДЗ вашего класса
- **Спец-ID** — чтобы вы могли войти на сайт без повторной регистрации
- **Домашние задания** — основная функция сервиса
- **Статистика** — для отображения активности класса

## 3. Кто видит ваши данные

- **Домашние задания** — видят все пользователи вашего класса
- **Ваше имя и username** — видят админы класса и создатели
- **Спец-ID** — видите только вы (в профиле)
- **Жалобы на админов** — видят модераторы и создатели
- **Сообщения в поддержку** — видят модераторы и создатели

## 4. Как хранятся данные

- **MongoDB Atlas** — облачная база данных (регион Frankfurt, Германия)
- **Шифрование** — все соединения по TLS
- **Пароли и коды** — хранятся только как SHA-256 хэши
- **JWT-токены** — хранятся как хэши в базе, оригинал только в cookie
- **Срок хранения ДЗ** — задания старше 14 дней удаляются автоматически каждую ночь

## 5. Ваши права

- **Удаление аккаунта** — через профиль в боте или поддержку
- **Изменение данных** — через профиль (смена класса, выход из аккаунта)
- **Получение копии данных** — напишите в поддержку
