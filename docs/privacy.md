# Политика конфиденциальности КлассныйБота

## 1. Какие данные мы собираем

КлассныйБот собирает следующие данные о пользователях:

- **Telegram ID**: уникальный идентификатор пользователя в Telegram
- **Имя и username**: имя и никнейм из Telegram (если указан)
- **Город, школа и класс**: выбранные при регистрации
- **Роль**: участник или админ
- **Статистика использования**: количество просмотров ДЗ, добавленных заданий, последнее действие
- **Выполненные задания**: список предметов с выполненными домашними заданиями

## 2. Зачем мы собираем эти данные

Данные необходимы для работы бота:

- **Telegram ID**: для отправки сообщений и идентификации пользователя
- **Имя и username**: для персонализации и отображения в профиле
- **Город, школа и класс**: для показа правильного домашнего задания и расписания
- **Роль**: для разграничения прав (админы могут добавлять ДЗ)
- **Статистика**: для анализа активности и улучшения сервиса
- **Выполненные задания**: для отслеживания прогресса пользователя

## 3. Кто видит ваши данные

- **Вы**: ваши данные видны только вам в вашем профиле
- **Одноклассники**: видят ваш город, школу и класс для определения общего класса
- **Админы класса**: видят вашу статистику активности
- **Создатели бота**: имеют полный доступ к данным для модерации и технической поддержки

Данные никогда не передаются третьим лицам и не используются в рекламных целях.

## 4. Как мы храним данные

- Данные хранятся в базе данных MongoDB Atlas
- База данных защищена современными методами шифрования
- Резервные копии создаются регулярно
- Доступ к базе данных ограничен авторизованным персоналом

## 5. Ваши права

Вы имеете право:

- Просмотреть свои данные в профиле бота
- Изменить город, школу или класс
- Изменить роль (с разрешения создателя)
- Удалить свой аккаунт (данные ДЗ и расписания класса сохранятся)
- Отозвать привязку Telegram

Для удаления аккаунта напишите создателю бота или используйте кнопку «Выйти из аккаунта» в профиле.

## 6. Контакты

По вопросам конфиденциальности обращайтесь к создателю бота.
