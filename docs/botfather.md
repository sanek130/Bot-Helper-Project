# Тексты для BotFather

Владелец вставляет их вручную через @BotFather. Код ничего не настраивает в BotFather автоматически.

## Имя бота

КлассныйБот

## About (до 120 символов)

КлассныйБот: домашние задания и расписание твоего класса. Регистрация за минуту.

## Description (до 512 символов, виден до нажатия Start)

КлассныйБот помогает школьникам не пропускать домашние задания. Смотри ДЗ на сегодня, завтра, послезавтра и на неделю, открывай расписание класса и выбирай любую дату через календарь. Админы класса добавляют задания в пару кликов, а жалобы на админов рассматривает создатель. Регистрация занимает меньше минуты. Нажми «Начать», чтобы попасть в бот.

## Команды (меню «/»)

```
start - Начать и зарегистрироваться
menu - Главное меню
today - ДЗ на сегодня
tomorrow - ДЗ на завтра
week - ДЗ на неделю
schedule - Расписание класса
profile - Мой профиль
web - Веб-версия
help - Помощь
```

## Аватар

Файл `assets/avatar.svg`, 512×512:
- фон #378ADD, без градиентов;
- значок: открытая тетрадь с галочкой, белый, плоский, без обводки;
- без текста внутри.

Установка: BotFather → `/setuserpic` → загрузить `assets/avatar.svg` (при необходимости сначала конвертировать в PNG 512×512).

## Пошагово

1. Открыть @BotFather.
2. Выбрать своего бота.
3. `/setname` — «КлассныйБот».
4. `/setabout` — текст About.
5. `/setdescription` — текст Description.
6. `/setcommands` — команды из блока выше.
7. `/setuserpic` — аватар.
8. При желании `/setmenubutton` — кнопка меню с адресом сайта.

## Privacy

Ссылка на `/privacy` указывается в описании сайта и в разделе «Помощь».
Команда `/setprivacy` в BotFather относится к работе бота в группах и к политике конфиденциальности не относится.

## Стиль сообщений

- `parse_mode: HTML`, заголовок раздела жирным в первой строке.
- Короткие строки, одна мысль на строку.
- Эмодзи только как маркеры: 📅, 📝, 📷, ✅, ☐, 🏫, ⚠️, ℹ️, 📢.
- Пользовательский ввод экранируется.
