# Тексты для BotFather

## Имя бота
КлассныйБот

## About (до 120 символов)
КлассныйБот: домашние задания и расписание твоего класса. Регистрация за минуту.

## Description (до 512 символов)
КлассныйБот помогает школьникам не пропускать домашние задания. Смотри ДЗ на сегодня, завтра, послезавтра и на неделю, открывай расписание класса и выбирай любую дату через календарь. Админы класса добавляют задания в пару кликов, а жалобы на админов рассматривает создатель. Регистрация занимает меньше минуты. Нажми «Начать», чтобы попасть в бот.

## Команды (меню «/»)
start - Начать и зарегистрироваться
menu - Главное меню
today - ДЗ на сегодня
tomorrow - ДЗ на завтра
week - ДЗ на неделю
schedule - Расписание класса
profile - Мой профиль
web - Веб-версия
help - Помощь

## Инструкция по установке

1. Открой BotFather (@BotFather)
2. Выбери своего бота
3. `/setuserpic` - загрузи файл `assets/avatar.svg`
4. `/setabout` - вставь текст About
5. `/setdescription` - вставь текст Description
6. `/setcommands` - вставь команды
7. При желании: `/setmenubutton` - добавь кнопку меню
