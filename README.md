# 📚 Homework Bot

Профессиональный Telegram-бот для управления домашними заданиями и расписанием уроков.

## 🎯 Возможности

### Для учеников
- 📅 Просмотр домашнего задания на сегодня, завтра и на неделю
- 🔍 Выбор конкретной даты для просмотра ДЗ
- 📖 Просмотр расписания уроков
- 👤 Личный профиль со статистикой
- 🔔 Уведомления о новых заданиях

### Для администраторов
- ✏️ Добавление и редактирование домашних заданий
- 📤 Загрузка расписания (фото)
- 📊 Статистика по классу
- 🗑️ Удаление устаревших заданий

## 🚀 Быстрый старт

### Требования
- Node.js 16+
- MongoDB
- Telegram Bot Token

### Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd homework-bot

# Установите зависимости
npm install

# Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env и добавьте ваши BOT_TOKEN и MONGODB_URI

# Запустите бота
npm start
```

### Переменные окружения

Создайте файл `.env` со следующими параметрами:

```env
BOT_TOKEN=your_telegram_bot_token
MONGODB_URI=mongodb://localhost:27017/homework-bot
PORT=5000
```

## 📋 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом |
| `/reg` | Зарегистрироваться |
| `/menu` | Главное меню |
| `/me` | Мой профиль |
| `/day` | ДЗ на сегодня |
| `/next_day` | ДЗ на завтра |
| `/weekend` | ДЗ на неделю |
| `/help` | Справка по командам |
| `/edit` | Редактировать ДЗ (админ) |
| `/stats` | Статистика (админ) |

## 🔧 Конфигурация

В файле `config.js` можно настроить:
- Максимальное количество отображаемых ДЗ
- Часовой пояс
- Поддерживаемые форматы фото
- Лимиты на длину текста

## 📊 Мониторинг

Бот предоставляет endpoints для проверки работоспособности:

- `GET /` - базовая проверка
- `GET /health` - расширенная информация (uptime, timestamp)
