## 🔧 Настройка

### Конфигурация админов
В файле `config.js` измените `adminChatIds`:
```javascript
adminChatIds: [YOUR_TELEGRAM_ID, SECOND_ADMIN_ID]
```

### Получение Telegram ID
1. Напишите боту `@userinfobot`
2. Скопируйте свой ID
3. Добавьте в `adminChatIds`

### Настройка MongoDB
1. Создайте базу данных на [MongoDB Atlas](https://mongodb.com/atlas)
2. Получите connection string
3. Добавьте в `.env` файл

### Настройка уведомлений
Уведомления работают по расписанию:
- **18:00** - уведомления о новом ДЗ
- **20:00** - напоминания о завтрашнем ДЗ

Изменить расписание можно в файле `notifications.js`:
```javascript
// Уведомления о новом ДЗ (каждый день в 18:00)
cron.schedule('0 18 * * *', () => {
  sendHomeworkNotifications();
});

// Напоминание о ДЗ на завтра (каждый день в 20:00)  
cron.schedule('0 20 * * *', () => {
  sendTomorrowReminder();
});
```

## 🔧 Устранение неполадок

### Бот не отвечает:
1. Проверьте токен в `.env`
2. Убедитесь, что бот добавлен в группу (если используется)
3. Проверьте логи в консоли

### Кнопки не работают:
✅ **Исправлено в новой версии!** Все обработчики `bot.action` добавлены.

### MongoDB ошибки:
1. Проверьте connection string
2. Убедитесь, что IP адрес разрешен в MongoDB Atlas
3. Проверьте права доступа пользователя базы данных

### Уведомления не приходят:
1. Проверьте настройки уведомлений пользователя
2. Убедитесь, что система уведомлений инициализирована
3. Проверьте логи cron задач
