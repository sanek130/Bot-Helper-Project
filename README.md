# КлассныйБот

Telegram-бот и сайт для школьников: домашние задания и расписание класса.

## Стек

- Node.js 20+
- ES-модули (`"type": "module"`)
- Telegraf 4
- Express 5
- Mongoose 8
- MongoDB Atlas

## Структура проекта

```
src/
├── index.js                 # запуск бота и Express
├── config.js                # конфигурация
├── db/
│   ├── connect.js
│   └── models/              # модели данных
├── data/
│   ├── cities.json
│   └── schools.json
├── bot/
│   ├── bot.js               # Telegraf, middleware, антиспам
│   ├── router.js            # команды и кнопки
│   ├── keyboards.js         # клавиатуры
│   ├── texts.js             # тексты
│   └── flows/               # логика бота
├── services/                # бизнес-логика
├── web/                     # Express и вебхук
└── utils/                   # утилиты
scripts/
├── migrate.js              # миграция данных
└── cleanup-homework.js     # автоудаление ДЗ
```

## Локальный запуск

1. Скопировать `.env` из `.env.example` и заполнить переменные
2. `npm install`
3. `npm run dev` (разработка с long polling)
4. `npm start` (продакшен с вебхуком)

## Миграция данных

Перед первым запуском новой версии выполнить миграцию:

```bash
npm run migrate
```

Скрипт создаст резервную копию в `backup/` и мигрирует данные.

## Деплой

Проект настроен для деплоя на Render. См. `render.yaml`.

## Функционал бота

### Регистрация
- 5 шагов: город → школа → буква класса → номер класса → роль
- Заявка на роль админа отправляется создателям
- Спец-ID для синхронизации аккаунтов

### ДЗ
- Просмотр на сегодня, завтра, послезавтра
- Неделя (7 дней)
- Календарь выбора дня
- Чеклист выполненных заданий
- Фото с подписями

### Админ
- Добавление ДЗ (текст или фото)
- Редактирование ДЗ (удаление фото, перенос на другой день, смена предмета)
- Удаление ДЗ
- Загрузка расписания
- Статистика класса
- Рассылка классу

### Создатель
- Всё из админа
- Рассылка любой группе (всем, по городу, школе, классу)
- Одобрение/отклонение заявок на админа

### Профиль
- Настройка нижней клавиатуры
- Выход из аккаунта (отвязка Telegram)
- Заявка на роль админа
- Спец-ID для копирования
