# КлассныйБот

Telegram-бот и сайт для школьников: домашние задания и расписание класса.

## Стек

- Node.js 20+
- ES-модули (`"type": "module"`)
- Telegraf 4
- Express 5
- Mongoose 8
- MongoDB Atlas

## Структура проекта

```
src/
├── index.js                 # запуск бота и Express
├── config.js                # конфигурация
├── db/
│   ├── connect.js
│   └── models/              # модели данных
├── data/
│   ├── cities.json
│   └── schools.json
├── bot/
│   ├── bot.js               # Telegraf, middleware, антиспам
│   ├── router.js            # команды и кнопки
│   ├── keyboards.js         # клавиатуры
│   ├── texts.js             # тексты
│   └── flows/               # логика бота
├── services/                # бизнес-логика

└── utils/                   # утилиты

├── migrate.js              # миграция данных

```

## Локальный запуск

1. Скопировать `.env` из `.env.example` и заполнить переменные
2. `npm install`
3. `npm run dev` (разработка с long polling)
4. `npm start` (продакшен с вебхуком)

## Миграция данных

Перед первым запуском новой версии выполнить миграцию:

```bash
npm run migrate
```

Скрипт создаст резервную копию в `backup/` и мигрирует данные.

## Деплой на Render

### Шаг 1: Подготовка MongoDB Atlas

1. Создаём аккаунт на [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
2. Создаём кластер M0 (бесплатный)
3. В Network Access добавляем `0.0.0.0/0` (IP Render динамические)
4. В Database Access создаём пользователя с правами readWrite
5. Копируем connection string и подставляем в `MONGO_URI`

### Шаг 2: Telegram-бот

1. Создаём бота через [@BotFather](https://t.me/BotFather)
2. Копируем токен в `BOT_TOKEN`
3. Устанавливаем имя бота (без @) в `BOT_USERNAME`
4. Настраиваем бота по инструкции в `docs/botfather.md`
5. Загружаем аватар из `assets/avatar.svg`

### Шаг 3: Render Blueprint

1. Пушим ветку `rewrite` в GitHub
2. Заходим на [Render](https://render.com)
3. Создаём New > Blueprint
4. Подключаем репозиторий и выбираем `render.yaml`
5. Вводим переменные окружения:
   - `BOT_TOKEN` - токен бота
   - `BOT_USERNAME` - имя бота (без @)
   - `MONGO_URI` - connection string MongoDB
   - `MODERATOR_IDS` - `5191412364,369745517` (или ваши ID)
   - `SITE_URL` - URL сайта (напр. `https://classbot.onrender.com`)
   - `WEBHOOK_URL` - то же самое, что `SITE_URL`
   - `WEBHOOK_SECRET` - автогенерируется
   - `JWT_SECRET` - автогенерируется
6. Нажимаем Apply и ждём деплоя

### Шаг 4: После деплоя

1. Проверяем `/health` - должен вернуть `{"status":"ok"}`
2. Отправляем `/start` боту
3. Проверяем сайт по `SITE_URL`
4. Заполняем контакт в политике конфиденциальности (`docs/privacy.md`)

### Шаг 5: Миграция данных

Если у вас есть старая база данных:

```bash
# Делаем бэкап
mongodump --uri="OLD_MONGO_URI" --out=backup

# Запускаем миграцию
npm run migrate
```

### Примечания

- Render генерирует случайный порт, поэтому указываем `PORT=10000` в envVars
- Вебхук устанавливается автоматически при первом запуске
- Cron job для очистки старых ДЗ запускается каждый день в 00:00 по Москве

## Функционал бота

### Регистрация
- 5 шагов: город → школа → буква класса → номер класса → роль
- Заявка на роль админа отправляется создателям
- Спец-ID для синхронизации аккаунтов

### ДЗ
- Просмотр на сегодня, завтра, послезавтра
- Неделя (7 дней)
- Календарь выбора дня
- Чеклист выполненных заданий
- Фото с подписями

### Админ
- Добавление ДЗ (текст или фото)
- Редактирование ДЗ (удаление фото, перенос на другой день, смена предмета)
- Удаление ДЗ
- Загрузка расписания
- Статистика класса
- Рассылка классу

### Создатель
- Всё из админа
- Рассылка любой группе (всем, по городу, школе, классу)
- Одобрение/отклонение заявок на админа

### Профиль
- Настройка нижней клавиатуры
- Выход из аккаунта (отвязка Telegram)
- Заявка на роль админа
- Спец-ID для копирования

- Создатели могут одобрять заявки на админа только через Telegram
