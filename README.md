# ДЗник — школьный бот домашних заданий

Telegram-бот на Telegraf + MongoDB: ДЗ по классу, расписание, напоминания, чеклист.

## Быстрый старт

1. Скопируй `.env` с `BOT_TOKEN` и `MONGODB_URI`
2. `npm install` → `npm start`
3. Тексты для [@BotFather](https://t.me/BotFather) — в [BOTFATHER.md](BOTFATHER.md)  
   Команды также выставляются автоматически при запуске (`setMyCommands`).

## Стиль UI

Словарь эмодзи, карточки дня и сетка кнопок — в [`ui.js`](ui.js).
