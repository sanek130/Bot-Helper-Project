# Инструкция по запуску бота

## 📋 Требования
- Node.js 16+
- MongoDB (локальный или облачный)
- Telegram Bot Token

## ⚙️ Установка

1. **Установите зависимости:**
```bash
npm install
```

2. **Настройте переменные окружения:**
Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=ваш_токен_бота_от_BotFather
DB_URI=mongodb://localhost:27017/school_bot
# или для MongoDB Atlas:
# DB_URI=mongodb+srv://user:pass@cluster.mongodb.net/school_bot
```

3. **Запустите бота:**
```bash
npm start
# или для разработки с авто-перезагрузкой:
npm run dev
```

## 🎯 Основные функции

### Для всех пользователей:
- **Регистрация (5 шагов):** ФИО → Город → Школа → Роль → Класс
- **📅 Моё ДЗ:** Умное отображение (сегодня/завтра в зависимости от времени)
- **🔔 След. урок:** Показывает следующий урок с временем и ДЗ

### Для учителей и админов:
- **📝 Обновить ДЗ:** Добавление/обновление домашних заданий
- **⚙️ Настройки:** Редактирование расписания звонков

## 🧹 Авто-очистка
- ДЗ автоматически удаляется через 14 дней после создания
- При обновлении ДЗ старое удаляется

## 🕐 Умные рекомендации
- **Воскресенье или вечер (после 18:00):** Бот рекомендует смотреть ДЗ на завтра
- **Утро/день:** Показывает ДЗ на сегодня

## 📁 Структура проекта
```
/workspace
├── index.js           # Главный файл бота
├── models/
│   ├── User.js        # Модель пользователя
│   └── Homework.js    # Модель ДЗ
├── .env               # Переменные окружения (не в git!)
├── .env.example       # Пример переменных
└── package.json
```

## 🔧 Формат добавления ДЗ
```
Предмет | Задание | Дата (ДД.ММ)
```
Пример: `Математика | №123 стр.45 | 25.10`

## 🔧 Формат расписания звонков
```
monday | 08:00-08:45, 09:00-09:45
tuesday | 08:00-08:45, 09:00-09:45
...
```
